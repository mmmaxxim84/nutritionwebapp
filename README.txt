WEB APP MENU SETTIMANALE
Versione gratuita, mobile, pronta per essere pubblicata.

Per ottenere il LINK che il paziente apre da Safari occorre pubblicare questa cartella su un hosting statico gratuito (es. GitHub Pages, Cloudflare Pages o Netlify).
Dopo la pubblicazione il paziente potrà aprire il link e, su iPhone, usare Condividi > Aggiungi alla schermata Home.

I dati del menu vengono salvati localmente nel browser del dispositivo.
